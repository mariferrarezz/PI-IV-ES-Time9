# Glossário

| Termo | Definição |
|---|---|
| Área afetada | Área estimada atingida por um problema, em hectares. |
| Área plantada | Área ocupada por uma plantação, em hectares. |
| Cultura | Espécie vegetal cultivada e cadastrada no catálogo. |
| Doença | Problema agrícola causado, em geral, por agentes patogênicos. |
| Ocorrência | Registro de um problema observado em uma plantação. |
| Monitoramento | Inspeção realizada em uma plantação, associada ou não a uma ocorrência. |
| Plantação | Cultivo de uma cultura em um talhão durante determinado período. |
| Praga | Organismo que causa prejuízo à cultura, como insetos ou ácaros. |
| Problema agrícola | Item do catálogo classificado como praga, doença, deficiência ou não identificado. |
| Propriedade | Unidade rural administrada por um usuário no sistema. |
| Talhão | Divisão delimitada da propriedade usada para organizar os cultivos. |
| Tratamento | Medida de controle aplicada a uma ocorrência. |
| Avaliação de tratamento | Registro do resultado observado após um tratamento. |
| Intensidade | Classificação da ocorrência: baixa, média ou alta. |
| Idempotência | Propriedade que evita criar vários registros quando o mesmo envio é repetido. |
| Firebase Authentication | Serviço usado para credenciais, login e tokens de autenticação. |
| MongoDB Atlas | Serviço em nuvem usado como banco de dados do ambiente. |
